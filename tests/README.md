# Testing Procedures

This directory tracks the testing methodology for the BOSC Community Library project.

## Manual Testing Harness
For the Phase 3 Mastery Challenge, the following manual tests were performed on `localhost`:
1. **Navigation:** Verified all anchor links resolve and close mobile menu.
2. **Responsive:** Inspected grid stacking at 900px and 760px.
3. **Search:** Validated case-insensitive filtering and empty states.
4. **Categories:** Confirmed state-based intersection between active categories and search queries.
